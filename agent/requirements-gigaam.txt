# Optional GigaAM STT backend (Sber, MIT) — installed as a NON-FATAL Docker layer.
# Activated at runtime with STT_BACKEND=gigaam. Falls back to faster-whisper if the
# onnx_asr import fails (see build_stt_service).
#
# CPU onnxruntime (NOT [gpu]). The GPU path kept fighting: a CUDA-13 onnxruntime-gpu
# (libcudart.so.13) on a CUDA-12 image, then a CUDA-12 pin left BOTH onnxruntime and
# onnxruntime-gpu installed (same module -> conflict). CPU avoids all of it, reuses
# the onnxruntime already in the image (used by Silero VAD), and is proven fast:
# GigaAM 0.6B RNN-T recognises a short utterance in ~0.15-0.3s on CPU.
onnx-asr[cpu,hub]
